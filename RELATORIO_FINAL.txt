PADRÕES IMPLEMENTADOS
================================================================================

1. MVI (Model-View-Intent) Pattern
   ✅ State: PresenceUiState (imutável, 1 única fonte de verdade)
   ✅ Action: PresenceAction (sealed interface para intenções do usuário)
   ✅ ViewModel: PresenceViewModel com onAction(action: PresenceAction)
   ✅ Composables: Root/Screen split (PresenceScreen com ViewModel)

2. Repositórios Reativos
   ✅ MqttRepository: Flow<DeviceState> para sincronização bidirecional
   ✅ LocationRepository: Flow<LocationData> com DataStore
   ✅ Singleton pattern com synchronized { } para thread safety

3. Jetpack Compose + Material Design 3
   ✅ Composables sem estado (Screen) + with ViewModel (Root)
   ✅ Scaffold, Card, Button, Slider com design limpo
   ✅ Canvas 2D para visualização de coordenadas

4. Persistência
   ✅ DataStore (Preferences) para coordenadas
   ✅ Sem SQL, sem Room - solução leve

5. Background Processing
   ✅ Foreground Service (PresenceService)
   ✅ WorkManager (MqttWorker)
   ✅ Coroutines com viewModelScope

6. Segurança
   ✅ SSL/TLS em porta 8883 (SSLSocketFactory)
   ✅ Credenciais via BuildConfig (não hardcoded)
   ✅ Runtime permissions (Android 6+)
   ✅ Permissões solicitadas: LOCATION (fine/coarse/background), NOTIFICATIONS
