SETUP PARA NOVOS DESENVOLVEDORES
=================================

1. Clone o repositório:
   $ git clone <repo>
   $ cd MqttMobileIot

2. Crie local.properties baseado no template:
   $ cp local.properties.example local.properties

3. Edite com seus dados REAIS:
   # local.properties
   sdk.dir=/seu/android/sdk
   mqtt.user=SEU_USER
   mqtt.pass=SEU_PASSWORD
   mqtt.host=ssl://SEU_CLUSTER_ID.s1.eu.hivemq.cloud:8883

4. Compile:
   $ ./gradlew clean build

5. Pronto! Credenciais carregadas automaticamente

ESTRUTURA RECOMENDADA EM PRODUÇÃO
==================================

App Android:
  1. User faz login (email/senha)
  2. Servidor autentica e emite JWT token
  3. App usa JWT para se conectar ao MQTT
  4. MQTT usa webhook para validar token
  5. Token expira em 1h (refresh automático)

Vantagens:
  ✓ Credenciais MQTT nunca no APK
  ✓ Fácil revogar acesso
  ✓ Auditoria de login
  ✓ Escalável para múltiplos usuários


LIMPEZA DO HISTÓRICO GIT (SE NECESSÁRIO)
========================================

Se credenciais foram acidentalmente commitadas:

1. Remover do histórico git:
   $ git filter-branch --tree-filter 'rm -f local.properties' HEAD

2. Force push (cuidado!):
   $ git push origin main --force

3. Notificar todos os devs para:
   $ git fetch
   $ git rebase origin/main

4. Mudar credenciais imediatamente no broker MQTT!
